# 🆓 Utiliser le Domaine Vercel Gratuit - Guide Rapide

## 🎯 Étapes pour Mettre le Domaine Vercel Gratuit

### Étape 1 : Aller dans les Settings de votre Projet

1. **Connectez-vous sur Vercel** : https://vercel.com
2. Cliquez sur votre projet déployé
3. Cliquez sur l'onglet **"Settings"** (en haut de la page)
4. Dans le menu de gauche, cliquez sur **"Domains"**

---

### Étape 2 : Ajouter un Nouveau Domaine Vercel

1. Dans la section **"Domains"**, vous verrez un champ de saisie
2. Tapez le nom que vous voulez pour votre domaine Vercel
   - Exemples :
     - `cours-mspc.vercel.app`
     - `mspc-education.vercel.app`
     - `formation-mspc.vercel.app`
     - `mspc-cours.vercel.app`

3. Cliquez sur **"Add"** ou **"Add Domain"**

4. **C'est tout !** ✅
   - Vercel crée automatiquement le domaine gratuit
   - Pas besoin de configuration DNS
   - HTTPS est activé automatiquement
   - Votre site est accessible immédiatement !

---

## 📝 Exemples de Noms Disponibles

Vous pouvez choisir n'importe quel nom disponible, par exemple :

- `cours-mspc.vercel.app`
- `mspc-formation.vercel.app`
- `education-mspc.vercel.app`
- `mspc-cours-online.vercel.app`
- `formation-mspc-tech.vercel.app`

**Règles :**
- ✅ Utilisez uniquement des lettres minuscules, chiffres et tirets (`-`)
- ❌ Pas d'espaces
- ❌ Pas de majuscules
- ✅ Longueur max : 63 caractères (mais restez simple !)

---

## ⚠️ Important Après le Changement

### Mettre à Jour Supabase

Après avoir ajouté votre nouveau domaine Vercel, vous devez dire à Supabase de l'autoriser :

1. **Dashboard Supabase** > **Settings** > **API**
2. Dans **"URL Configuration"**, ajoutez votre nouveau domaine
   - Exemple : `https://cours-mspc.vercel.app`
3. Cliquez sur **"Save"**

Cela permet à l'authentification de fonctionner correctement.

---

## ✅ Vérification

Une fois ajouté :

1. Le domaine apparaît dans la liste avec une coche verte ✅
2. Votre site est accessible sur `https://votre-nom.vercel.app`
3. Partagez cette URL avec vos étudiants !

---

## 🔄 Si Vous Voulez Changer le Nom Plus Tard

Vous pouvez :
1. Aller dans Settings > Domains
2. Cliquer sur **"Edit"** à côté du domaine
3. Changer le nom
4. Sauvegarder

C'est aussi simple que ça ! 🎉
